# 学习记录格式

学习记录放在 `./learning-records/`，顺序编号：`0001-slug.md`、`0002-slug.md`……目录惰性创建：写第一条记录时才建。

它们是教学版的 ADR：捕捉非显然的教训、关键洞见、用户自述的既有知识——这些会左右后续会话，用来计算最近发展区。

## 模板

```md
# {学到或确立了什么的短标题}

{1–3 句：学到了什么（或确立了什么既有知识），以及它为什么影响后续会话。}
```

格式就这么多。一条学习记录可以只有一个段落。价值在于记录 _这已被知道_ 和 _它为什么改变下一步教什么_，不在填满小节。

## 可选小节

只在真正增加价值时加，大多数记录用不上：

- **Status** frontmatter（`active | superseded by LR-NNNN`）：早先的理解被证明有误并被取代时有用。
- **Evidence**：用户如何展示了理解（答对一个问题、完成一个练习、引用既有经验）。这条记录可能被翻案时有用。
- **Implications**：这为后续会话解锁或排除了什么。非显然时值得记。

## 编号

扫 `./learning-records/` 里现有的最大编号，加一。

## 什么时候写

任一为真就写一条：

1. **用户对非显然的东西展示了真正的理解**：不只是接触过，而是有能正确使用该概念的证据。这抬高下一步教学的地板。
2. **用户披露了既有知识**："我已经会 X 了。" 记下来，后续会话不再重教；声明的深度也一并记。
3. **一个误解被纠正**：用户之前相信了错的，现在明白为什么。这类高价值：它们预测相邻主题的未来绊脚石。
4. **mission 因学习而移动**：用户发现自己在意的和原本以为的不同。交叉链接 [[MISSION.md]] 并更新它。

### 什么不构成学习记录

- 只是教过的内容。覆盖不等于学会，等证据。
- 已被 [[GLOSSARY.md]] 紧凑收录为术语定义的内容，不重复。
- 逐会话的活动日志。学习记录不是日记，是决策级洞见。

## 取代

后一条记录与早一条矛盾时（用户的理解加深或被纠正），给旧记录标 `Status: superseded by LR-NNNN`，不删除。理解如何演化的历史本身就是有用信号。
