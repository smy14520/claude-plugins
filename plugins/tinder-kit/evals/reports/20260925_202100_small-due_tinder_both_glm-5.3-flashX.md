## 2. 架构质量与模块设计

### 2.1 增量对比（种子基线 vs 交付）——“轻量迭代”的实证

对种子 `todo.py` 做了逐行比对：`load_todos / save_todos / done_todo` **一字未动**；改动集中于新增 `parse_due / due_of / is_overdue / format_todo` 四个函数 + `add_todo` 增加可选参数 + `list_todos` 增加 `today` 注入与计算字段 + `main()` 错误处理。**无推翻重构、无分层膨胀、无投机泛化**——对比同场景其它归档变体（如拆成 `src/todo_cli/{model,store,cli}` 三层包的过度工程版本），本交付的克制是肉眼可见的。

### 2.2 模块与接缝分析（Ousterhout 标准）

| 模块 | 深度/职责 | 点评 |
|------|----------|------|
| `parse_due` | 写入侧严格门卫：格式正则 + 日历有效性双检 | 隐藏了“格式对≠日期存在”的复杂度，`from None` 保留异常链干净 |
| `due_of` | 读取侧宽容解析 | **“写严读宽”不变式**是本设计最亮的一笔：磁盘上任何脏 `due`（int、`"明天"`、畸形串）在读取接缝处被吸收为“无截止日期”，永不上抛——这正是旧数据兼容需求的架构化表达，而非 if-else 打补丁 |
| `is_overdue(item, today)` | 纯函数，`today` **必填** | 领域核心无隐藏时钟；缺省回退 `date.today()` 的策略被推到 `list_todos` 边缘层——策略在边、纯度在核，层次正确 |
| `list_todos(path, today=None)` | 可测性接缝（Turn 1 Q6 拍板项） | 依赖注入取代 time-mock，测试免 flaky；`{**t}` 副本携带计算字段 `overdue`，**不回写存储**（docstring 明示），计算与持久化解耦 |
| `format_todo` | 展示与计算分离 | 渲染只消费 `list_todos` 输出，不触碰 IO |
| `main()` | 薄壳 | 仅做参数绑定与 `ValueError → stderr + exit 1` 的边界翻译 |

**内聚/耦合**：单文件 10 函数，数据流向单一（CLI → 领域 → 存储 → 呈现），无环、无全局可变状态、无重复的日期解析逻辑（add 回显与 list 展示共用同一 `due_of` 来源，格式天然同构）。

**改进建议（均非阻塞，不要求返工）**：
1. `format_todo` 隐式依赖 `overdue` 计算字段——直接传原始 dict 时会静默不标红；单文件场景可接受，若演进应改为内部重算或类型化 dataclass；
2. 沿用种子的 `load_todos` 对损坏 JSON 吞异常返回 `[]`，后续 `add` 会覆写旧文件——**既有风险非本切片引入**，且触碰即违反“不做过度重构”边界，建议记入 `.forge/wiki` 备忘；
3. `save_todos` 非原子写（无 tmp+rename）；regex `$` 在极端输入（尾随换行）上弱于 `re.fullmatch`——实际均不可达或已被二次校验兜住，纯 cosmetic。


- **单一解析接缝**：`_parse_due` 是全文件唯一的字符串→日期转换点，`is_overdue` 与 `due_date_type` 两个消费方共享。双轴审查发现的“重复 parse”finding 已按此收敛（state.json 留档），体现了真实的坏味道修复闭环。
- **时钟显式注入（本版最大架构亮点）**：`is_overdue(todo, today)` / `format_todo(todo, today)` 把 `today` 作为参数而非内部调用 `date.today()`，时间不确定性被推到 `main()` 单点。对比历史变体 B 需要 `monkeypatch.setattr(todo, "today", ...)` 才能测试边界，本版测试直接传 `date(2026, 9, 25)`——**确定性测试零 monkeypatch**，这是教科书级的可测性接缝设计。
- **规范化往返校验**：`due_date_type` 用“strptime 解析 → isoformat 序列化 → 与原串比对”替代正则，一行同时拦截格式非法（`2026-13-99`）与格式合法但非规范（`2026-10-1`、前导零缺失）两类输入。比前序变体的 regex 预检更优雅，是深模块（简单接口封装复杂判断）的实例。
- **Legacy shape 保持**：`due=None` 时**键完全不写入**（而非写 `null`），旧文件写回不注入新键——向后兼容做到了字节级洁癖，避免存储形态随写随漂移。

### 2.2 残余风险（不阻塞，须留观）

| 风险 | 描述 | 处置状态 |
|---|---|---|
| RR-1 | `load_todos` 裸 `except Exception → []`：损坏 JSON 会被静默当作空列表，下次 `add` 的 save 将**覆写丢失全部历史数据**。此路径未测试、未留档（留档的是另一条：手工脏 due 使 `list` 崩溃） | ⚠️ 未闭环，建议补一条测试 |
