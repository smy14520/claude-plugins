## 0. 审计方法与证据链披露（先说清楚证据强度）

本次评测执行了三级核查：

1. **档案核查**：场景产物生成于评测沙箱，本工作区仅留存场景底牌（`scenarios/large-wiki/`）。为不依赖转写文本自证，审计员依据转写中**逐字给出的 10 个源码模块中的 9 个全文 + 8 个测试文件全文**，在 `.audit_scratch/wiki_verify/` 完成了逐字节忠实重建（含 `frontmatter.py` 中不可见的 UTF-8 BOM 字面量，已用 `od` 核验为 `ef bb bf`），并逐条人工推演全部 **55 个测试用例**与源码逻辑的一致性 —— **未发现任何一处测试与实现相矛盾**。
2. **限制声明**：本会话沙箱对 pytest/python 脚本实机执行需人工审批，未能现场跑出 `55 passed` 的实测回执。故测试通过性结论基于"忠实重建 + 静态逐例推演"，置信度高但非实机背书；`cli.py` 在转写中被截断（`_cmd_links` 起约百余行缺失），审计员按 spec CLI 契约与测试断言补全后才可运行 —— **该尾段属"契约一致"而非"原文核验"**。
3. **红线扫描**：重建后全量 `grep` 导入清单 —— 运行时依赖**仅** `argparse/json/sys/pathlib/re/dataclasses/os/collections.abc`，**零三方依赖、零 sqlite3、零 subprocess（工具绝不碰 git）**，与 ADR-0001/0002 及需求绝对禁令完全一致。

| 不做 Web/git 同步/多用户 | 无任何越界代码；Q9 拍定工具零 git 副作用 | ✅ 完全兑现 |

### 1.2 偏差审计：一处已披露、零处隐性偷懒

- **已披露偏差**：底牌写"页面标题匹配优先"，开发者将其升级为 Q6（"CJK 全文检索策略"）抛出裁决，督导官拍定"子串匹配 + 命中次数粗排"。决策可追溯至 spec 账本（Q6 行）——**这是走完把关程序的语义变更，不是静默缩水**。
- **残差（本报告唯一实质功能保留意见）**：`search()` 的 haystack **仅含正文**，标题文本完全不参与匹配。标题含关键词而正文不含的页面将无法被搜到——即使按"命中次数粗排"的新语义，标题理应至少占一票权重。属已批准语义下的实现收窄，建议 v1.1 将 `title` 计入 haystack 并加权。
- **技术诚实性加分**：底牌与督导答复均口误提过"倒排索引"，开发者敢于在 spec 中纠正为"内存线性扫描（子串语义下最优，替代口误的'倒排'）"——技术上完全正确（倒排索引服务不了子串语义），且留痕备查，这是罕见的对上游权威的技术纠偏。
- **超出底牌的增益**：重复标题体检（底牌未要求，且与 ADR-0003 身份语义闭环）、`prose.py` 围栏/行内代码统一净化、doctor 豁免清单、确定性 JSON 落盘。

### 1.3 统一语言与决策留痕

- **CONTEXT.md**：13 个核心术语全部配 `_Avoid_` 负面清单（如 索引→_Avoid: database/缓存_，检索→_Avoid: grep/搜索引擎_），直接约束工单命名与代码命名——这是防术语漂移的高杠杆资产，质量显著高于一般交付。
- **ADR×3**：每条均有 Considered Options（含否决理由）/ Consequences / Revisit When 三段式，决策因果链完整（0001 索引形态 → 0002 零依赖 → 0003 页面身份，三者互相引用支撑）。
- **spec 决策账本**：19 项决策全部编号回链到访谈问题（Q1–Q17 + 3 项一致性裁定），做到"每个行为都能回答是谁在何时拍板"。

**小结：忠实兑现、决策全留痕、唯一偏差已披露已批准。扣 1 分给"标题不入检索域"的实现收窄残差。**

## 2. 架构质量与模块设计 —— 9/10

### 2.1 分层与依赖图（实测重建核对，无环、单向）

```
cli.py（展示薄壳：build_index 一次 → 分发子命令）
 ├─ indexer.py（编排：扫描 → 解析 → 组装）
 │   ├─ frontmatter.py   ┐
 │   ├─ links.py ──┐     ├─ 均只依赖 prose.py / model.py
 │   ├─ tags.py ───┴─ prose.py（净化器，被两者复用）
 │   └─ model.py（Page / WikiIndex，纯数据 + title_map）
 ├─ search.py（引擎，只依赖 model）
 └─ doctor.py（体检，只依赖 model）
```

### 2.2 深模块亮点

- **`prose.py` 是本次架构的最佳手笔**：代码围栏与行内代码的净化是一个"隐藏的重要实现复杂度"，开发者把它从链接与标签两条扫描路径中抽出为单一接缝（一致性裁定 ①），links 与 tags 各自只享受"正文行迭代器"的简单接口——复杂度被吞进模块内部，这正是 Ousterhout 深模块定义的教科书式落地。
- **`model.py` 小而深**：`WikiIndex.title_map()` 用一个方法同时服务了链接解析判定、doctor 死链/孤岛/重复标题三处，且"重复标题全部保留、歧义上交 doctor"的语义选择写得明明白白。
- **CLI 真·薄壳**：argparse 定义 + `build_index` 一次 + 纯转发，无业务逻辑渗漏；退出码语义（0/1/2）收敛清晰。
- **正确性策略自洽**：ADR-0001"每命令全量重建"换取消灭缓存失效问题，随后所有实现（backlinks 线性扫、doctor 线性扫）都与该哲学一致——没有出现"宣称全量重建、暗地里搞增量缓存"的架构分裂。

### 2.3 扣分点

- 底牌点名的 **LinkGraph 图拓扑模块未独立成形**：图逻辑分散在 `model.title_map`（静态）与 `doctor/cli` 的线性扫描（动态）之间，缺少一个能回答 `backlinks(page)` 的图接口。当前规模（个人数千页）完全合理，但这意味着未来若引入锚点级建链或邻接缓存，要动三处而非一处——接缝前瞻性略欠。
- `search._snippet` 仅按第一个关键词定位摘要，多词 AND 命中时摘要可能不含第二关键词（轻微体验瑕疵）。

**小结：高内聚低耦合实测成立，prose.py 抽象是亮点；LinkGraph 未独立命名是唯一的架构Mapping残差。**

### 3.2 质量评述

- **真测试而非摆设**：断言打到具体值（如 `("py", 2), ("rs", 1)`、`[{"source": "a", "target": "ghost"}]`），不是 `assert result` 式糊弄；CJK 场景贯穿链接/标签/检索三层，正是本场景最容易偷工的接缝。
- **防回归背书有效**：一致性裁定 ①②③（围栏排除、标签归一、自链不计）各自由多文件测试交叉锁定，术语表改动或重构破坏语义会立刻红。
- **测试基建干净**：`vault` fixture 每次生成独立子目录，同测试多库互不污染——这是能撑住 Large System 级测试增殖的基建。
- **缺口**：① 无打包/`console_scripts`/`python -m wikicore` 冒烟测试（entry point 断链只有发版才会发现）；② 无规模基准（场景名为 large-wiki，却无千页库延迟数据佐证 ADR-0001"毫秒级"论断）；③ 隐藏**文件**（非目录）是否入索引无测试，`scan` 只过滤隐藏目录，存在轻微不对称；④ 无 `--root` 缺省走 cwd 的用例。

**小结：8.5 分——接缝真实、断言扎实、对抗用例丰富；扣在打包冒烟与规模背书缺失。**

### 结论：**PASS —— 评级 A**

这是一次可作范本的 Large System 快车道交付：**红线（禁数据库）零违逆、偏差（检索语义）全部显式裁决并留痕、决策（19 项账本 + 3 ADR + 术语表）三层留痕闭环、55 个测试与实现经审计重建逐一推演自洽**。开发者敢于纠正上游"倒排索引"口误并以线性扫描论证，体现了对技术事实的忠诚优先于对权威表述的顺从——这正是内核型工程最需要的品质。

**未给 A+ 的三个理由**：① 标题文本完全不参与检索匹配，"标题匹配优先"的精神只剩正文命中数一具躯壳；② 场景冠名 large-wiki 却无规模基准数据背书 ADR-0001 的性能论断；③ `cli.py` 转写截断使尾段仅能契约级核验、打包入口无冒烟测试。

### 移交后续开发者的三条建议（优先级序）

1. **v1.1 检索域补题**：`haystack = f"{page.title}\n{page.body}"` 并对标题命中加权（如 ×2），一个改动同时兑现底牌原文与新语义；
2. **补冒烟与基准**：一条 `test_packaging`（`console_scripts` 入口 + `python -m wikicore --help`）+ 一条千页合成库的 `build/search` 延迟基准，坐实 ADR-0001 的 Revisit When 阈值；
3. **`_snippet` 多词摘要**：任选一个已在当前页命中的关键词定位窗口，消除 AND 命中下摘要脱靶的体验瑕疵。
