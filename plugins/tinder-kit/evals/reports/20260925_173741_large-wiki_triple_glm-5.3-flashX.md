### 1.2 偏差审计：一处已披露、零处隐性偷懒

- **唯一实质偏差**：底牌口径提过「轻量内存倒排索引」，实际检索为**按页面清单流式现读 + 子串 AND 匹配**。开发者在 Turn 13 **主动如实披露**而非隐瞒，且技术上完全正确——子串语义（尤其 CJK 无分词）下倒排索引根本服务不了，流式子串才是该语义下的正确实现。督导随即终局拍板（红线仅“纯本地+零外部数据库”一条）。**这是走完把关程序、有决策留痕的口径修正，不是静默缩水**，且属于对上游措辞的技术纠偏，应记加分而非扣分（扣分仅因字面口径未 100% 复现，占 0.5）。
- **无功能残缺**：底牌五项功能全部到位，无一项缩水为空壳。
- **超预期增益**：重名页体检（与 ADR-0001 身份语义闭环，“歧义不算死链、根因交重名暴露”的一致性裁定有测试锁定）、畸形 Frontmatter 体检、`links` 出链命令、`build` 强制重建、`--json` 双位置（子命令前后均可）、BOM 容错与编码降级不中断体检。

### 1.3 统一语言与决策留痕

- **CONTEXT.md**：结构/链接/页面/标签/检索/体检六域术语，全部配 `_Avoid_` 负面清单（如 索引→_Avoid: 数据库、存储层_；匹配→_Avoid: 模糊匹配_），且把「已知局限」（普通 MD 链接不解析）诚实写进词汇表而非藏进代码——这是防术语漂移的高杠杆资产。
- **ADR×2**：均有真实的 Considered/Consequences 论证。ADR-0001 用“链接应随文件移动而保持有效”论证扁平命名而非路径命名；ADR-0002 正面处理了“SQLite 免费又标准”这一最强反方，写明不承诺十万页级——**这是说理而非盖章式的假 ADR**。
- Turn 1–9 的 9 个访谈包（只读边界、命名/根目录、链接解析五分歧、匹配严格语义、frontmatter 边界、标签五规则、存储与检索、体检包、收尾合同）全部在 CONTEXT.md / ADR / 代码 docstring 中可回溯，“每个行为都能回答是谁在何时拍板”。

**小结：忠实兑现 + 超配增益 + 唯一偏差已披露已裁决。扣 0.5 分给「倒排索引」字面口径残差。**

## 2. 架构质量与模块设计 —— 9/10

### 2.1 分层与依赖图（实测核对，无环、单向）

```
cli.py（展示薄壳：argparse 定义 + 装配分发 + 退出码/双输出契约）
 ├─ indexer.py（编排：collect → build → 缓存指纹校验 → 原子写回）
 │    └─ parser.py（frontmatter 切分 / wikilink / #tag / 围栏状态机——全部棘手度在此消化）
 ├─ query.py（backlinks / resolve_target / tag / search，只依赖 model+parser）
 ├─ audit.py（纯函数 audit(index) → AuditReport，只依赖 model+query）
 └─ model.py（frozen dataclass：WikiLink / Page / Index + by_name/by_tag 派生视图）
```

### 2.2 深模块亮点

- **`parser.py` 是本次架构的最佳手笔**：严格匹配语义、锚点/别名剥离、外链识别、围栏（同字符且不短于开栏）、行内代码的保守剔除规则（不闭合只留首段）、`#` 触发的负向断言——全部易碎复杂度被封死在一个模块内，向外只暴露 `parse_page / scan_body / split_frontmatter` 等窄接口。Ousterhout 意义上的深模块教科书式落地。
- **接口即纯数据接缝**：`query`/`audit` 全部以 `Index`（frozen dataclass）为出入参，无 IO、无全局态——这直接解释了测试为何能“面向接缝”高密度铺开。
- **不可变域模型**：三个 dataclass 全线 `frozen=True`，缓存往返相等性（`cached == built`）因此可作为强断言。
- **缓存协议自洽**：`文件系统是唯一真相` 落到实处——walk+stat 指纹比对、schema 版本字段、损坏/缺字段/类型错一律按不存在处理重建（`_index_from_json` 返回 None 而非修复），与 CONTEXT.md「索引损坏的正确处理方式永远是重建」完全一致；没有出现“宣称可丢弃、暗地里搞增量修复”的架构分裂。
- **CLI 薄壳有真契约**：退出码 0/1/2 三态语义、stdout 只出结果 / stderr 只出错误、`argparse` 父子解析器用 `SUPPRESS` 解决 `--json` 双位置的默认值覆盖问题（并有注释说明）。

### 2.3 扣分点

- **热路径性能 smell（本次最实质的技术保留意见）**：`audit()` 对每条链接调用 `resolve_target`，而后者每次都重建 `index.by_name()` 字典——复杂度放大为 O(页数×平均链数×页数)。个人库数百页无感，但 ADR-0002 自己承诺“数万页秒级”，万页 Vault 下 doctor 会先痛。一行局部缓存即可消除，属低成本未做。
- **LinkGraph 未独立成形**：图逻辑分散在 `model.by_name`（静态视图）与 `query.resolve_target/backlinks`（线性扫描）两处，缺少独立图接口。当前规模合理，但未来若加邻接缓存或锚点级建链，要动两处。
- `_load_index()` 是对 `indexer.load()` 的无谓转发层；`_snippet` 只按第一个命中词定位窗口，多词 AND 命中时摘要可能脱靶（体验瑕疵，同款问题也见于同类实现）。

**小结：高内聚低耦合实测成立，parser 深模块 + 纯数据接缝 + 不可变模型是三大亮点；热路径 dict 重建是唯一实质架构债。**
