# Spec: Todo CLI 截止日期支持（todo-due-date）

Status: ready-for-agent
Date: 2026-09-25

## 需求

在现有 Todo CLI 基础上增加截止日期支持：

1. `add` 命令支持可选参数 `--due YYYY-MM-DD`；
2. `list` 展示未完成任务时，若当前日期已超过截止日期，在末尾标注 `[OVERDUE]`；
3. 数据存放在现有单 JSON 文件（`.todos.json`）中，保持向后兼容。

## 已裁决决策（Frontier 裁决记录）

| # | 决策 | 裁决 |
| :-- | :--- | :--- |
| D1 | 存储字段 | 键名 `due`，严格 `"YYYY-MM-DD"` 字符串；旧任务**缺省该键**（非 `null`）。见 ADR-0001 |
| D2 | 逾期判定 | 严格 `today > due`；截止日当天不算逾期 |
| D3 | 展示格式 | due 存在即展示：`[2] 交房租 (due: 2026-09-30)`；逾期追加 `[OVERDUE]` |
| D4 | 时间源接缝 | 模块级 `today()` 包装 `date.today()`（本地时区）；判定抽纯函数 `is_overdue(todo, on)` |
| D5 | 输入校验 | 严格 `%Y-%m-%d` 解析；非法输入报错退出码 2，不写文件 |
| D6 | 排序 | 不排序，保持插入（id）顺序；排序留作独立后续决策 |
| D7 | 过去日期 | 允许 `--due` 指向过去，静默接受（补录历史欠账） |

## Agreed Seams

- **存储接缝**（既有）：`add_todo` / `list_todos` / `done_todo` 均接受 `path` 参数，测试用 `tmp_path` 注入；
- **时间接缝**（新增）：`todo.today()` 为唯一时间源，测试通过 monkeypatch 注入假日期；逾期判定为纯函数 `is_overdue(todo, on: date) -> bool`，不直接读钟。

## Out of Scope

- list 排序（按 due 升序等）— 独立后续决策（D6）；
- 时刻级（时分秒）提醒；
- 对 `done` 命令或已完成任务的任何改动（`list` 本就只展示未完成任务）；
- 存储格式迁移、schema 版本号（ADR-0001 明确不引入）；
- 损坏 JSON 的容错语义变化（现状：静默当空表，维持原样）。

## 验收标准（公共行为）

1. `add --due 2026-10-01 任务` → 文件中该任务含 `"due": "2026-10-01"`，其余任务无该键；
2. `add --due 2026-13-40 x` → 退出码 2，stderr 报错，文件内容不变；
3. 旧格式文件（任务无 `due` 键）被 `list`/`done` 正常读取，输出无 `(due: …)`、无 `[OVERDUE]`；
4. 假设今天是 2026-09-25：due `2026-09-24` → 输出含 `[OVERDUE]`；due `2026-09-25` → 不含（当天不算逾期，D2）；due `2026-09-26` → 不含；
5. 有 due 未逾期任务输出形如 `[1] 标题 (due: 2026-09-26)`；
6. 既有 CRUD 测试行为不变（回归）。
