# 单一 JSON 文件本地存储

本工具是单用户本地 CLI Todo，数据规模为个人量级（万条以下）。拍定：全部任务持久化在单个 JSON 文件（默认 `~/.todo/todo.json`，可用 `TODO_HOME` 环境变量覆盖目录），采用 temp + rename 原子写入；每次成功写盘前将旧文件轮转为 `.bak`，作为损坏/误操作的唯一自救线。坚决不引入任何数据库。

## Considered Options

- **SQLite**：事务与并发查询更强，但文件不可直读、不可 git diff，徒增概念负担 — 否决：单用户单进程场景用不上这些能力；
- **todo.txt 纯文本**：人类可读、可 grep，但解析规则脆弱，标签之外的字段（时间戳等）难以扩展 — 否决：扩展性是硬伤。

## Consequences

- 接受的代价：无增量写、无跨进程并发锁（单用户单进程假设下可接受）；全量读写在个人量级下是毫秒级操作；
- `.bak` 只保留上一代，误操作的一次性恢复窗口为一轮写盘。

## Revisit When

- 出现多设备同步或协作需求（JSON 格式将成为迁移负担）；
- 任务量级进入十万条以上，或引入全文检索需求。
