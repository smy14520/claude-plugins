# Todo CLI（本地待办清单）

本地单用户 CLI 待办工具的统一语言词汇表。所有工单、代码命名与交流以此为唯一术语基准。

## Language（领域统一语言表）

**Todo**:
清单中的一条待办事项；只有两种状态——未完成（open）与已完成（done）。
_Avoid_: task, 事项, 条目, 待办条目

**Tag**:
挂在 Todo 上用于归类与过滤的关键词；一个 Todo 可挂多个 Tag。
_Avoid_: 分类, category, label

**Priority**:
Todo 的紧急程度，固定三档：high / med / low。
_Avoid_: importance, 重要性, 级别
