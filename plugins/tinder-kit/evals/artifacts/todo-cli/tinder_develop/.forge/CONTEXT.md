# CONTEXT — 统一语言词汇表

本文件是 todo-cli 项目的统一语言（Ubiquitous Language）真实源。
所有工单标题、代码命名、测试用例名、CLI 文案必须使用本表术语，严禁漂移到 `_Avoid_` 列中的同义词。

## 核心词汇

| 术语 | 定义 | _Avoid_ |
| :--- | :--- | :--- |
| **任务 (Task)** | 待办清单中的一条记录，仅含 `id`、`text`、`tags`、`done` 四个字段 | 条目、item、记录、事项 |
| **标签 (Tag)** | 挂在任务上的分类词；一个任务可含多个，顺序保留、自动去重 | 分类、category、分组 |
| **过滤 (Filter)** | `list -t` 按标签筛选的机制；多标签之间为 **AND** 语义（任务须同时含有全部指定标签） | 搜索、search、query、查询 |
| **完成 (Done)** | 任务的布尔状态；`done` 命令单向置位，不做 toggle | 勾选、check、关闭、close |
| **未完成 (Open)** | `done == false` 的任务；`list` 默认只显示 Open | 活跃、active、pending |
| **编号 (ID)** | 任务的正整数标识，从 1 起自增，删除后**永不复用**（由存储的 `next_id` 保证） | uuid、hash、序号 |
| **存储文件 (Store)** | 单一 JSON 持久化文件，默认 `~/.todo/todos.json`，可被 `TODO_FILE` 环境变量覆盖（见 ADR-0001）。**硬约束（2026-09-25 拍板）：存储必须为本地单一 JSON 文件，禁用任何数据库** | 数据库、database、db、仓库 |

## CLI 命令面（已敲定）

`add` / `list` / `done` / `rm` / `tags` — 仅此五个，无别名。

- `add` 经可重复的 `-t/--tag` 参数挂标签；
- `tags` 计数口径为**全量任务（含已完成）**，输出按计数降序、同数按名称码点升序 —— 与 `list` 的默认 Open 视图口径不同，属刻意设计（tags 是标签词汇总览，不是任务视图）。

## Out of Scope（v1 明确不做）

- 行内 `#标签` 解析（v2 再议）
- `edit` / `undo` 命令；任务优先级、截止日期、提醒
- 多设备同步、多进程并发写入
- 颜色 / 表格等富文本输出
