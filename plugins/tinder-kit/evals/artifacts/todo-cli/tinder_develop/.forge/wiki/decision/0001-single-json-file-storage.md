# ADR-0001: 本地持久化采用单一 JSON 文件

- **状态**: Accepted
- **日期**: 2026-09-25

## 背景（Context）

todo-cli 是单用户本地 CLI 工具，任务数据需要跨会话持久化。候选方案：单一 JSON 文件、SQLite、每任务一个文件。

## 决策（Decision）

- 全部任务存于**单一 JSON 文件**，默认路径 `~/.todo/todos.json`；
- 路径可被环境变量 `TODO_FILE` 覆盖 —— 该环境变量同时是**测试接缝**（测试注入 `tmp_path`，无需 mock 全局状态）；
- 写入采用**原子替换**：先写同目录临时文件，再 `os.replace` 覆盖，杜绝半写损坏；
- 文件损坏/不可解析时**报错退出（exit 1），绝不静默重置** —— 用户数据安全优先于可用性；
- `next_id` 随数据一并持久化，保证 ID 删除后永不复用；载入时以 `max(next_id, max(ids)+1)` 自愈手工编辑造成的漂移；
- 技术栈纯标准库（`json` + `pathlib` + `argparse`），不引入数据库或序列化依赖。

## 后果（Consequences）

- ✅ 人类可读、可手工备份与修改、零第三方依赖；
- ✅ 过滤在内存中完成（全量载入后做集合运算），单用户数据量下性能无虞；
- ⚠️ 不支持多进程并发写入（最后写入者胜）—— 与 Out of Scope 一致；
- ⚠️ 数据量达数万条时全量载入变慢 —— 届时重议并升级存储（触发新 ADR）。
