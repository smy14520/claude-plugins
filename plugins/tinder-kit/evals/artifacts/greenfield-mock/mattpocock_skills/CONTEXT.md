# Mock Server

一个轻量本地 HTTP API Mock 服务的领域词汇表。服务器把本地契约文件中的每条路由映射为固定的模拟响应，用于纯本机的开发与联调。

## Language

**契约 (Contract)**:
本地 `mocks.json` 文件的整体：所有路由及其模拟响应的唯一真值来源。
_Avoid_: 配置文件、规则集、spec

**契约快照 (Contract Snapshot)**:
启动时一次性读入并校验的契约副本，是服务器此后全部行为的完整依据；改契约必须重启进程，服务器运行期间不感知文件变化。
_Avoid_: 热加载、动态刷新

**路由 (Route)**:
契约中的一条条目，把一个 HTTP 方法与字面路径的组合映射到一个固定的模拟响应。同一 path 配不同 method（如 `GET /api/user` 与 `POST /api/user`）是两条互相独立的路由，不共享任何内容。
_Avoid_: 接口、端点、handler

**静态路由 (Static Route)**:
仅按字面路径匹配的路由：路径按字节精确匹配（查询串忽略在外），method 大写归一，除此之外无任何隐式行为（路径参数、通配符、正则、HEAD 自动映射等均不属于本工具）。
_Avoid_: 动态路由

**模拟响应 (Mock Response)**:
契约中为某条路由预先声明的完整 HTTP 响应，由状态码与 JSON 响应体组成；请求头、请求体、查询串均不影响响应内容。
_Avoid_: stub、假数据

**无状态 (Stateless)**:
服务器不记忆任何请求；每个响应严格由契约静态决定，与请求历史无关。

**未匹配 (Miss)**:
请求未命中任何路由时服务器的固有行为：恒 404，响应体为回显请求方法与路径的固定 JSON。它不属于路由，契约写不出、也覆盖不了它；不做 405 细分，诊断靠回显。
_Avoid_: 兜底响应

**访问日志 (Access Log)**:
每个请求一行、打到 stdout 的人类可读记录，为操作者的眼睛服务。它不是 API，不被任何程序消费。
_Avoid_: 结构化日志、JSON lines
