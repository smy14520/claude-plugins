# 团队任务平台（Team Task Platform）

由单机 todo.py 演进而来的小团队（约 10 人）任务协作平台。本词汇表是统一语言真实源：所有工单、代码命名、讨论必须使用本表术语。

## Language

**任务**:
分派给团队成员、带有归属人与截止日、完成状态对全团队可见的工作单元。
_Avoid_: 待办、事项（旧单机 todo 语境）、issue

**归属人**:
任务所指派、并对按时完成负责的团队成员。
_Avoid_: 负责人、owner、执行人

**截止日**:
任务约定应当完成的日期。
_Avoid_: 到期时间、DDL、deadline

**同步**:
多端访问服务器上同一份共享数据、改动即时可见的语义；本项目明确不含离线编辑与冲突合并。
_Avoid_: 离线同步、实时协同（指后续增强语义，非本项目当前承诺）、数据镜像
