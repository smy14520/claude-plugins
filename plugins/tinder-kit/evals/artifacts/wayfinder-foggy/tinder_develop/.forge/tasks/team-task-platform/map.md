## Notes

领域：约 10 人内部团队的任务协作。每个 session 先读 `.forge/CONTEXT.md` 对齐词汇，再动工。

Charting 访谈已拍板的 standing preferences（后续 session 不得重新争论）：

- **技术栈**：Python + FastAPI，延续现有代码
- **部署**：单台机器 + Docker；无专职运维、数据不涉密，怎么简单怎么来
- **同步语义**：服务器中心化，多端看同一份数据；离线优先明确排除
- **团队现状**：靠公司 IM（哪家未确认）+ 口头派活；杀手场景 = 任务有归属人和截止日、完成情况一眼可见
- **存量数据**：现存 `.todos.json` 必须迁入新平台（一次性迁移脚本）；旧 CLI 迁移完成后废弃
