Type: grilling
Status: needs-triage
Blocked by: None

## Question

任务实体（`.forge/CONTEXT.md` 中的「任务」）的完整形态是什么？

- **归属人**：单选还是多选？
- **状态机**：待办/进行中/完成三态，还是延续旧模型的 open/done 两态？
- **分组**：MVP 要不要列表/项目分组，还是先全局一个池子？
- **评论/附件**：进不进 MVP？
- **旧字段映射**：旧模型的 id/title/done 如何映射到新模型？

验收线：必须支撑杀手场景——「任务有归属人和截止日、完成情况一眼可见」。术语以 `.forge/CONTEXT.md` 为准，新概念先入册再使用。
