# Spec: wikicore —— 本地 Markdown 个人 Wiki 知识库管理内核

## 目标

用 Python 构建本地 Markdown 个人 Wiki 管理内核：双向链接 `[[page]]` 解析与反向引用查询、`#tag` 分类聚合、全文检索、死链/孤岛/重复标题体检；纯本地文件 + 极简单文件 JSON 索引，**严禁任何数据库（含 SQLite）与外部检索服务**。

## 非目标（Non-goals）

- 任何数据库、远程检索服务、远程 git 同步；
- GUI/TUI/渲染器 —— 内核只产出查询结果与索引；
- frontmatter title/aliases 富身份解析（见 ADR-0003）；
- 锚点存在性校验、标签自动补全、模糊"did you mean"；
- 工具自身触碰 git（含自动改写 `.gitignore`）。

## CLI 契约

```text
wiki [--root PATH] <command> [args] [--json]

build                       重建并落盘 .wiki_index.json，打印摘要（页面/链接/标签计数）
backlinks <page>            反向引用列表；页面不存在 → exit 1
links <page>                出链列表，死链目标显式标注
tags [tag]                  无参：全部标签+页面计数（按计数降序）；带参：该标签下页面
search <关键词>...          全文检索（AND 子串），输出命中页+次数+上下文摘要
doctor [--strict] [--ignore <page>]...   体检报告 + 语义化退出码
```

- 人类可读输出使用中文分节标签（如 `反向引用 · 页面「X」（2）：`）；
- `--json` 输出 `ensure_ascii=False` 的稳定结构（键排序、列表有序）；
- 退出码：`0` 正常；`1` 业务失败（doctor 有发现、页面不存在）；`2` 用法错误。

## 索引 Schema（`.wiki_index.json`）

```json
{
  "schema": 1,
  "pages": [
    {
      "title": "页面名",
      "path": "相对根目录的 posix 路径.md",
      "links": ["排序去重后的出链目标"],
      "tags": ["小写归一、排序去重"]
    }
  ]
}
```

`pages` 按 `(title, path)` 排序；索引永远可丢弃重建（ADR-0001）。

## 词法细则

- 链接：`\[\[([^\[\]]+?)\]\]`；取 `|` 前段，再取 `#` 前段，去首尾空白；空目标（自锚点）跳过；页内去重保序；
- 标签：`#` 前不能是文字字符或 `/`；标签字符为 Unicode 文字字符 + `-` + `/`，首字符必须是文字字符；跳过 `^\s{0,3}#{1,6}\s` 的 heading 行；
- frontmatter：首行 `---` 且存在闭合 `---` 才成立（未闭合视为无 frontmatter）；仅识别 `tags:` 键（行内数组 / 逗号分隔 / 多行 `- ` 列表；去引号、去 `#` 前缀）；frontmatter 不参与链接、行内标签与检索扫描。

## 解析歧义规则

- 重复标题：全部保留于索引；指向该名的链接视为"存活但歧义"，反向引用分发给所有同名页面；重复本身由 doctor 必报；
- CLI 取页面时重名取 `(title, path)` 排序第一个。

## 验收标准

1. `pytest` 全绿：覆盖 frontmatter 三种写法、链接语法（别名/锚点/自锚点/围栏/行内代码/去重）、标签词法（CJK/嵌套/heading 排除/代码排除/大小写归一）、扫描（跳过隐藏目录与 node_modules、仅 `.md`、重复标题）、检索（AND/大小写/排序/摘要/frontmatter 排除）、体检（死链/孤岛/自链不豁免/重复/退出码含 `--strict`）、CLI 端到端（`--json` 结构、退出码、落盘索引）；
2. `pip install -e .` 后 `wiki` 命令可用，`python -m wikicore` 等效；
3. 真实演示库上六条命令全部产出正确结果（运行证据留存）。
