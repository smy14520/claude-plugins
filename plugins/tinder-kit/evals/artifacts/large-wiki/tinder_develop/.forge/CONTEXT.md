# wiki-cli

个人本地 Markdown 知识库的结构洞察工具。本词汇表是 wiki-cli 全部工程产出的统一语言真实源。

## Language

**Vault（知识库）**:
一个目录及其下全部页面构成的集合，是 wiki-cli 的唯一分析对象。
_Avoid_: 仓库、语料库、数据库

**Page（页面）**:
vault 中任意一个 `.md` 文件；页面名即去掉扩展名的文件名。
_Avoid_: 文件、词条

**Link（链接）**:
页面正文中 `[[页面名]]` 形式的跨页引用；别名写法 `[[页面名|文字]]`、路径写法 `[[子目录/页面名]]` 与锚点写法 `[[页面名#小节]]` 均属链接。链接是有向的，"双向"仅指可沿正反两个方向查询，链接本身没有双向属性。
_Avoid_: 双链、内链

**Backlink（反向引用）**:
来自其他页面、指向本页面的链接；是判定孤岛的唯一依据。
_Avoid_: 反链、被引用

**Tag（标签）**:
正文 `#名称` 形式的内联主题标记。标签只做主题聚合，不构成页面间引用关系，不影响孤岛判定。
_Avoid_: 话题、分类、主题

**Dead Link（死链）**:
在页面名解析规则下无法对应到任何页面的链接。
_Avoid_: 断链、坏链、失效链接

**Orphan（孤岛页面）**:
反向引用数为零的页面；自链接不算反向引用。
_Avoid_: 孤儿页、孤立页面

**Ambiguous Link（歧义链接）**:
解析目标对应多个同名页面的链接；其反向引用记入每个候选页面，并在体检中单独报告。
_Avoid_: 冲突链接、重名链接

**Doctor（体检）**:
对整个 vault 扫描死链与孤岛页面的健康检查。
_Avoid_: lint、健康检查
