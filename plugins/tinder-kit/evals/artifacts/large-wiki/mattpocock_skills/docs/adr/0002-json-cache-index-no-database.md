# 索引为单文件 JSON 缓存，拒绝包括 SQLite 在内的一切数据库

索引只是 Vault 的派生缓存：可随时删除并全量重建，永远不承载真相。选 JSON 单文件而非 SQLite（尽管 SQLite 是标准库、单文件、且 FTS5 可免费提供全文检索）是因为：本工具的用户价值前提是「极简、可审计、零部署负担」——索引文件必须能被用户直接 `cat`、`git diff`、手动删除；引入数据库会换来一档永不兑现的检索性能，付出的却是可审计性与「缓存即真相」的心理污染。规模前提：个人 Vault（数百至数万页），全量重建的耗时以秒计，增量优化的复杂度不值得。

后果：检索能力受限于自实现的匹配策略（见检索模型），性能上限以「个人库规模」为界，不承诺十万页级。
