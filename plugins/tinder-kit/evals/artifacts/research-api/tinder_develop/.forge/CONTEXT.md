# Release Watch

观察 GitHub 仓库正式发布节奏的命令行小工具的领域词汇表。

## Language

**正式 Release (Official Release)**:
GitHub 仓库中已对外发布、且不处于草稿或预发布状态的 Release。
_Avoid_: 稳定版, stable version, 正式版

**发布时刻 (Published At)**:
Release 面向公众可见的时刻；「最近」排序与「距今天数」均以它为唯一锚点。
_Avoid_: 创建时间, created time

**距今天数 (Age in Days)**:
自发布时刻到当前时刻经过的整日数，不足一日不计。
_Avoid_: 存续天数, age（裸用）
