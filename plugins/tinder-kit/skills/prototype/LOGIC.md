# Logic Prototype（业务逻辑与状态机原型）

一个单一、自包含的 HTML 文件——一个**可分享的独立 Demo**——让任何人点击按钮就能驱动底层状态模型。

适用于问题围绕 **业务逻辑（business logic）、状态流转（state transitions）或数据结构（data shape）** 的场景，即那些纸面上看着很合理、但只有真正跑过具体 Case 才会发现卡壳反直觉的东西。

因为它是一个文件、无需安装任何依赖或启动本地服务器，你可以直接双击打开，或者把它发给产品经理、设计师或业务专家，让他们亲手感受这个模型。

---

## 核心构建步骤

### 1. 明确问题（State the question）
动手前，在 Demo 顶部醒目处写下一段话：本次原型正在验证哪个状态模型、回答什么具体问题。

### 2. 将核心逻辑封装在小巧纯粹的模块中（Isolate logic）
在单个 `<script>` 块中，将真正承载逻辑的代码写成一个纯粹的小模块：
- **Pure reducer**：`(state, action) => state`；
- **State machine**：显式的状态（states）与流转表（transitions）；
- **纯函数集合**：无隐式内部状态，仅纯数据变换。
- **纪律**：保持逻辑纯净，不要与 DOM 耦合；界面按钮调用该逻辑，逻辑通过纯数据驱动渲染。

### 3. 构建可交互界面（HTML Shell）
为非技术人员设计，界面包含三部分：
1. **状态面板（State Panel）**：醒目展示当前内部所有状态字段；
2. **自由操作区（Free-play Buttons）**：列出当前合法的所有动作按钮，点击即可触发状态流转；
3. **引导式步进场景（Tabbed Guided Walkthroughs）**：按常见业务场景（如：正常退款流、并发取消流、异常超时流）排布出 1、2、3 步的操作按钮，一键按序模拟。
