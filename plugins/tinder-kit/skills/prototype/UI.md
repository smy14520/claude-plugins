# UI Prototype（界面形态与布局原型）

在单一路由或页面上生成**几种截然不同（Radically Different）的 UI 变体（Variations）**，并通过浮动底栏或 URL 参数极速切换。用户在浏览器里来回切换变体，选中最满意的一个（或从每个变体中借鉴一部分亮点），然后将其余抛弃。

适用于问题围绕“这个界面应该长什么样”、“哪种排版手感最好”的场景。

---

## 两种形态（强烈优先选择形态 A）

### 形态 A：贴着现有页面运行（Preferred）
- 路由已存在：变体直接渲染在同一路由上，通过 `?variant=1` / `?variant=2` 区分；
- 真实数据、真实侧边栏、真实字体密度：在真机环境中判断最容易，不会陷入空路由的虚假美感中。

### 形态 B：独立 Throwaway 原型页面（Last Resort）
- 只有被验证的东西完全没有现有宿主页面可放时才用；
- 按照项目既有路由规范创建一个显式带有 `prototype` 标识的临时页面，同样支持多变体切换。

---

## 核心纪律

1. **默认做 3 个截然不同的变体（Radically Different Variants）**：
   - 变体之间要有本质区别（如：紧凑极简风 vs 仪表盘卡片风 vs 向导向步进风），不要只是改个按钮颜色；最多不超过 5 个；
2. **轻量切换栏**：
   - 在页面底部提供醒目的固定浮动条，允许用户一键在 Variant 1 / 2 / 3 之间无缝切换对比。
