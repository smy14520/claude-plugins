# Audit — 代码库与架构双轴体检流

站在系统长期演进与维护者视角，对当前工作区或特定模块进行系统性深度体检。

## 审计双轴

1. **宏观架构轴（调用 `architect`）**：
   - **放置裁决**：核心机制与实体的归属是否清晰？是否存在第二入口？
   - **不可逆预警**：是否有现在便宜但未来推翻代价极大的架构债务？
   - **形态退化**：依赖方向是否腐化？是否存在虚假/投机抽象？
2. **微观代码轴（调用 `review`）**：
   - **Fowler 12 味坏味道**：重复代码、过长方法、依恋情结、基本类型偏执等；
   - **深模块度量**：接口是否足够薄？内部实现是否良好封装？

## 输出格式

产出清晰结构化报告：
- **高风险项（Critical / Irreversible）**：建议立即重构的放置错误或契约缺陷；
- **优化机会（Opportunities）**：可加深模块、清理坏味道的具体 file:line；
- **只提供建议与改法，不直接改动代码**：交由人类拍板是否立项重构。
