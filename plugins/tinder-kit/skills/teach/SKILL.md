# Teach — 跨会话教学工作区

以“知识-技能-智慧”模型，跨会话带领用户深入掌握一个全新的技术栈或复杂概念。

## 教学工作区八件套（围绕特定主题目录）

- `MISSION.md`：用户学这个主题的核心原因与期望；
- `GLOSSARY.md`：本工作区规范术语表；
- `RESOURCES.md`：可信权威资源清单（绝不轻信未经核实的参数化记忆）；
- `./learning-records/*.md`：学习记录（类比 ADR），沉淀教训与关键洞见，用于计算最近发展区（ZPD）；
- `./lessons/*.html`：自包含互动课程；
- `./reference/*.html`：速查参考文档；
- `./assets/*`：跨课程组件；
- `NOTES.md`：工作备忘与用户偏好。

## 教学推进循环

1. **定位最近发展区（ZPD）**：通过问答和前序记录，判断用户当前处于舒适区边界的哪个位置；
2. **高质量讲授与互动**：用自包含的 HTML 演示或代码实验展开练习；
3. **沉淀与更新**：更新 learning-records，为下一次会话留存认知锚点。
